# ResuTailor.ai: published site

This repository holds only the built website served at https://madhavvan.github.io/restail/.
The application's source code is private; every file here is the output of its build.

The PDF editor (under `editor/` and `editor-runtime/`) is Folio, built on PyMuPDF and MuPDF. It is
free software under the GNU Affero General Public License v3.0 or later. Its complete source
code, with build instructions, is in [`editor/source.zip`](editor/source.zip), which is also
linked from inside the editor.
